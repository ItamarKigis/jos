=== Q Describe your solution.
===   (free form, up to 500 words, don't need to use all 500!))
created 3 additional mon functions for monitor, the same way as mon_backtrace:
    mon_showmappings
    mon_setpageflags
    mon_memdump

showmappings
    - accepts start_va and end_va
    - iterates from start_va to end_va, jumps by page sizes
    - for each VA representing a page, calls walk_pgdir and uses
      the PTE data to print a VA->PA + flags mapping.

setpageflags
    - accepts a VA and flags
    - calls walk_pgdir to get the address of the corresponding PTE
      overwrites the lower 12 bits of the PTE with the flags argument

memdump
    - accepts an physical/virtual flag and an address
    - if physical, adds KERNBASE to the address.
    - calls a helper memdump_va function that assumes a virtual address
    - memdump_va prints 128 bytes, 16 rows of 8 bytes.
      each row with the following structure: addr: bytes ascii
      (similar to xxd terminal util output)
